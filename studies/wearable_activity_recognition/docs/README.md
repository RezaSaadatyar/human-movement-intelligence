# HARTH Research Documentation

The completed HARTH v2.0 activity-recognition study comprises 27 executed numbered investigations. This directory provides one consolidated scientific account instead of separate stage-by-stage planning documents.

**Start here:** [Research Methods and Experimental Evidence](HARTH_RESEARCH_METHODS_AND_EVIDENCE.md). It covers the dataset and activity task, time-safe preprocessing, participant splitting, classical and temporal models, sampling and calibration studies, the matched benchmark, multi-seed robustness, frozen model selection, qualified held-out findings and scientific limitations.

**Original evidence:** [Notebooks 01–27](../notebooks/) · [Study results](../README.md) · [Versioned evidence and approval records](../evidence/) · [Scientific figures](../images/).

**Reproducibility:** See the [source and integrity audit](../../../docs/HARTH_REPRODUCIBILITY.md). Original Stage 23/24 executed evidence remains available through pinned Git history. The Stage 25 historical pending proposals and separate approved qualified-Test record remain unchanged. The final evaluation is same-study and qualified, not blind external validation.

The superseded stage-specific plans remain recoverable from Git history; they are not active instructions for rerunning the protected Test.
