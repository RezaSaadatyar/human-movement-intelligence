# Repository-wide research visuals

The [repository overview](repository_overview.svg) is the visual map for the main [Human Movement Intelligence README](../README.md). It distinguishes:

- **Executed:** HARTH wearable activity recognition with its own [study workflow](../studies/wearable_activity_recognition/images/study_overview.svg) and 27 [stage diagrams](../studies/wearable_activity_recognition/images/).
- **Exploratory:** BoneNet biomechanical load estimation, shown in a separate [source-to-pilot diagram](../studies/biomechanical_load_estimation/images/study_overview.svg).
- **Planned:** Other movement, gait, markerless, neurorehabilitation and multimodal studies without completed experimental results.

Each image is an editable SVG, not a screenshot. The portfolio image shows shared research practices, **not** a claim that every study completed all modelling or evaluation stages.

See [research visual documentation standards](../docs/RESEARCH_VISUAL_STANDARDS.md).
